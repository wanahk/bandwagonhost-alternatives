**Q: Is CN2 GIA necessary, or will CN2 GT be enough?**

It depends. CN2 GT (the $49.99/year BandwagonHost entry tier) is significantly better than standard routing — less congestion, lower latency than raw BGP. CN2 GIA is the premium tier where latency holds stable during peak hours. For personal blogs or dev environments, CN2 GT is usually sufficient. For production apps serving Chinese users, CN2 GIA makes a real difference.

**Q: BandwagonHost says it's "self-managed" — what does that actually mean?**

You get root access to a Linux server, the KiwiVM control panel to manage it, and infrastructure-level support if hardware fails. BandwagonHost won't help you configure Nginx, debug your WordPress install, or set up a firewall. If that's what you need, Hostinger's guided approach is more appropriate.

**Q: What happens if my BandwagonHost IP gets blocked by the GFW?**

BandwagonHost doesn't offer automatic IP replacement — you'd need to open a support ticket and may need to pay for a new IP. DMIT offers free IP swaps every 15 days on some plans, which is a meaningful advantage for users in mainland China.
